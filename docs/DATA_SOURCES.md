# COSMOS KIDS data and media sources

## V1 planetary texture baseline

| Field | Value |
| --- | --- |
| Dataset | Solar System Scope 2K Solar Textures |
| Provider | [Solar System Scope / INOVE](https://www.solarsystemscope.com/textures/) |
| Scope | Sun, Moon, eight planets, layered Earth, Venus atmosphere, Saturn rings |
| Projection | Equirectangular for globes; Saturn rings use a radial RGBA strip |
| Resolution | 2048 × 1024 for globe maps; 2048 × 125 for Saturn rings |
| License | [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/) |
| Canonical manifest | [`public/assets/textures/solar-system/sss-2k/manifest.json`](../public/assets/textures/solar-system/sss-2k/manifest.json) |
| Runtime catalogue | [`data/manifests/assets.manifest.json`](../data/manifests/assets.manifest.json) |

The source files are downloaded and hash-checked by `scripts/download-assets.mjs`. Local files are checked by `scripts/validate-assets.mjs`; pass `--remote` to verify the live upstream bytes as well. Attribution documents are reproducibly generated by `scripts/generate-attributions.mjs`.

## Processing

- Source JPEG and Saturn-ring PNG pixels are preserved; files are only renamed locally.
- Earth normal and specular maps are converted from TIFF to RGB PNG because browsers do not reliably decode TIFF.
- Color and emissive maps are intended for sRGB sampling. Normal and specular maps are data textures and must use a linear/no-color-space interpretation.
- Earth clouds are an opaque grayscale JPEG; use luminance as opacity. Saturn rings contain meaningful RGB and alpha channels.

## Scientific and pedagogical caveats

- Solar System Scope states that unmapped gaps may be filled with fictional terrain and that colors are slightly more saturated than natural color.
- The pack does not publish an observation date, instrument, or processing lineage for each individual texture.
- The Sun texture is a static photosphere visualization, not a solid surface or a live full-Sun observation.
- The Venus surface is a radar-derived, false-color educational view normally hidden by its opaque cloud deck.
- Earth day, night, cloud, normal, and specular maps are composites from different products and times; the cloud layer is not live weather.
- Jupiter, Saturn, Uranus, and Neptune maps depict dynamic cloud envelopes rather than solid surfaces and should not be presented as current weather.
- Uranus and Neptune colors are processed and saturated; their apparent color difference must not be described as exact natural color.
- Saturn rings are represented by a radial RGBA strip, not a physical particle or radiative-transfer model.

This V1 pack is a coherent visual baseline, not a time-resolved or instrument-traceable scientific dataset. UI copy must distinguish natural color, enhanced color, radar-derived views, composites, and reconstructed areas.
